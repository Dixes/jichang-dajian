# 面板节点分组与倍率设置

当节点超过 5 个，机场就需要「分组」来组织：按地区、按线路质量、按套餐等级划分，让用户一眼找到合适的节点。「倍率」则决定流量如何扣费，是机场定价策略的核心工具。本文讲 Xboard 里分组与倍率的完整配置方法。

## 准备工作

先盘点现有节点，按用途分成几类，例如：

- 香港/日本/新加坡：主力低延迟组
- 美国/欧洲：大流量组
- 家宽住宅 IP：解锁专线组

想清楚套餐怎么卖：是所有节点全开放，还是低价套餐只能用部分组？分组和倍率必须和套餐定价一起设计，单独调没有意义。

## 新建分组

Xboard 后台 → 节点管理 → 分组，新建分组并命名，建议命名规范统一：

```
HK-主力 / JP-主力 / US-大流量 / 家宽-解锁
```

命名带地区和用途，后期节点多了不会乱。每个节点在编辑时选择所属分组，一个节点可以属于多个分组，跨组的节点会同时出现在多个分组列表里，适合「主力节点全套餐可见」的场景。

注意：分组是用户可见的组织方式，不要把「测试节点」「备用节点」这类内部命名暴露给用户，单独建隐藏分组或直接不分配。

## 倍率设置：流量怎么扣

倍率（rate）决定用户使用该节点时流量的扣除系数。倍率 1 表示用 1GB 扣 1GB，倍率 2 表示用 1GB 扣 2GB，倍率 0.5 则只扣 0.5GB。

常见策略：

```
主力低延迟组：倍率 1      # 基准
大流量组：倍率 0.5        # 鼓励用户用便宜带宽，缓解主力压力
家宽解锁组：倍率 2-3      # 成本高，用倍率覆盖成本并抑制滥用
深夜时段：可设定时低倍率  # 引导错峰（需配合任务计划）
```

倍率的本质是价格杠杆：把用户往成本低的节点赶，把高成本节点的用量压下来。调倍率前先算清每个节点的单位流量成本，倍率 × 套餐单价要能覆盖。

## 套餐与分组的绑定

Xboard 套餐设置里可以指定该套餐可见的节点分组。典型搭配：

- 入门套餐：仅「大流量组」，倍率低，适合价格敏感用户
- 标准套餐：「主力组 + 大流量组」
- 高级套餐：全部分组含「家宽解锁组」

这样形成价格阶梯，用户为了解锁能力自然升级套餐。修改套餐分组后，已购用户实时生效，升级立即解锁新分组，这是促进续费升级的有效手段。

## 验证

用测试账号分别购买不同套餐，检查：

1. 订阅链接里是否只出现该套餐可见分组的节点
2. 用 100MB 流量后，后台统计的扣除量是否符合倍率（倍率 2 应扣 200MB）
3. 分组改名或节点换组后，订阅是否及时更新

```bash
# 订阅链接节点数快速检查
curl -s "https://panel.example.com/api/v1/client/subscribe?token=xxx" | grep -o "remarks" | wc -l
```

节点数对不上就去查分组绑定，别让用户先发现。

## 常见坑

一是新节点忘了分配分组，用户订阅里看不到，白白浪费服务器。二是倍率设反：把高成本节点设成低倍率，用户全涌过去，成本爆炸。三是分组名含敏感词或内部黑话，被用户截图传播。四是频繁改倍率不通知用户，引起「偷流量」质疑，调价前先公告。
