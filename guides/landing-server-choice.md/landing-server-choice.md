# 落地机怎么选：线路、带宽与住宅 IP

落地机是用户流量的最终出口，它的线路质量直接决定延迟，带宽决定晚高峰速度，IP 类型决定解锁能力。选错落地机，后面再怎么调优协议都补不回来。本文讲清楚机场选落地机的三个维度和实测方法，帮你把钱花在刀刃上。

## 准备工作

明确你的用户画像：主要用户在哪个地区、主要用途是浏览还是流媒体、预算范围。准备几个候选机房的测试 IP 或试用机，先实测再批量采购。不要凭商家宣传页下单，线路这东西只有实测数据可信。

准备测试工具：

```bash
# 本地或中转机上安装
apt install -y mtr iperf3
```

`mtr` 看路由跳数和丢包，`iperf3` 测真实带宽，两者结合才能判断一台机器的真实水平。

## 线路：看三网回程质量

对国内用户为主的机场，重点看电信、联通、移动三网的回程路由。用 mtr 从候选落地机反向测到你的目标用户地区：

```bash
mtr -rw --tcp -P 443 目标测试IP
```

好的线路特征：跳数少（通常 10 跳以内）、每一跳延迟平稳递增、无丢包。CN2 GIA、CU VIP 这类优化线路晚高峰依然稳定，普通 163 骨干晚高峰可能丢包严重。线路优先级：直连优化线路 > 普通直连 > 绕路欧美。记住，落地机到用户的「最后一公里」质量，决定了用户感受到的全部延迟。

## 带宽：看晚高峰真实可用带宽

商家标的带宽多是峰值或共享带宽，晚高峰 20:00-23:00 才是考验。用 iperf3 在晚高峰打流测试：

```bash
# 服务端
iperf3 -s -p 5201
# 客户端
iperf3 -c 服务端IP -p 5201 -t 60 -P 8
```

`-P 8` 开 8 个并行流，接近真实多用户场景。如果标称 1Gbps 实际只能跑 200Mbps，那就是共享带宽超售严重。机场选落地，建议按「每用户晚高峰 5-10Mbps」估算总带宽，留 30% 余量。带宽不够时用户最先感知的是视频卡顿，投诉也最多。

## IP 类型：机房 IP vs 住宅 IP

机房 IP（IDC IP）便宜、稳定，适合做通用流量节点；住宅 IP（ISP/家庭宽带 IP）解锁流媒体和某些风控严格的服务能力更强，但价格贵 3-10 倍，且质量参差。

```bash
# 查 IP 类型与信誉
curl -s ipinfo.io/203.0.113.10/org
```

看 ASN 归属判断是 IDC 还是 ISP。建议搭配使用：机房 IP 做主力大流量节点，住宅 IP 做小众解锁专线，在面板里分组定价（见分组与倍率篇）。不要全押住宅 IP，成本扛不住；也不要指望机房 IP 解锁所有流媒体。

## 下单前的检查清单

- 三网 mtr 晚高峰各测一次，记录延迟和丢包
- iperf3 晚高峰打流，记录真实带宽
- 确认 IP 没进常见黑名单（查 Spamhaus 等）
- 确认商家允许的用途和流量政策，避免「无限流量」文字游戏
- 先买一台跑一周，稳定再批量

```bash
# 快速黑名单检查示例
dig +short 10.113.0.203.zen.spamhaus.org
```

有返回即被列入，换 IP 或换商家。

## 常见坑

一是只看价格买最低价，晚高峰卡成 PPT，用户流失比省下的钱贵得多。二是被「独享带宽」话术忽悠，不实测就批量采购。三是住宅 IP 买到「假住宅」（机房 IP 伪装），解锁依然失败，坚持看 ASN。四是忽视 IPv6，很多机房 IPv6 路由一塌糊涂，落地机先确认 IPv4 质量再考虑 v6。
