# 机场成本核算：一台机场每月花多少钱

搭机场之前先算账：服务器、域名、中转、落地，加起来一个月到底多少钱？这篇把各项成本拆开讲清楚，帮你判断自建划算还是直接买订阅划算。

## 准备工作

成本分四块：面板服务器、落地节点、中转机、域名。先列清单再逐项估价：

```
成本清单：
1. 面板服务器（放 Xboard + 数据库）：1 台
2. 落地节点（用户实际连接）：N 台
3. 中转机（可选，优化线路）：M 台
4. 域名：1 个/年
```

数量按你的用户规模定：自用 1 台落地机就够，小圈子 2-3 台。

## 逐项成本

面板服务器：1 核 1G 的境外小鸡即可，月付约 ¥20-40。面板本身不吃资源，用户量不大时最低配就行。

落地节点：这是大头。普通 VPS（1T 流量）月付约 ¥30-60；CN2 GIA 等优质线路月付 ¥80-200；住宅 IP 节点更贵，月付 ¥150 起。节点数量 = 用户数 ÷ 单节点承载，单节点按 20-50 用户估。

中转机：按需购买，普通 NAT 小鸡月付 ¥10-20 一台。不是必须，线路已经好的节点可以省掉。

域名：普通域名年付约 ¥60-100，摊到每月 ¥5-8。

举例（自用 + 小圈子，1 面板 + 2 落地 + 1 中转）：

```
面板小鸡：¥30/月
落地节点 x2：¥50 x2 = ¥100/月
中转机：¥15/月
域名摊销：¥6/月
合计：约 ¥150/月
```

## 验证

```bash
# 用 vnstat 看实际流量，核对是否买大了
vnstat -d
# 面板看用户数和流量，算单用户成本
# 单用户月成本 = 月总成本 ÷ 付费用户数
```

跑一个月后复盘：流量用不满就降配，节点空载就合并。成本核算不是做一次就完，每季度看一次。

## 常见坑

一是上来就买顶配，GIA、大带宽、住宅 IP 全上，结果 5 个用户，钱全浪费。二是只算服务器不算时间：运维、排错、换 IP 都是时间成本，时薪折算进去可能比服务器贵得多。三是带宽超量：买了 1T 流量的机器，用户跑超了要么限速要么加钱，套餐定价时要留余量。四是年付陷阱：年付便宜但商家跑路就全亏，新商家先月付试水。
